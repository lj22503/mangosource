# MangoSource · 投资资源地图

按「你遇到什么」分层的投资资源导航。七个层：投资场景 / 投资工具 / 投资大师 / 投资 Skill / 投资词典 / 投资提示词 / 投资工作台。

作者：燃冰（10 年金融产品人）。做的是投资平权。

## 结构

```
index.html          单文件站点（零依赖、零外部请求）
share/              可分享的卡片源文件
  01-can-i-buy.html 能不能买 · 五问拆解卡（1080×1440）
assets/             卡片成品图
docs-用户卡点设想.txt  200 条用户卡点的原始整理
```

## 本地看

直接双击 `index.html`。没有构建、没有依赖、没有网络请求。

## 内容原则

- 不荐股、不预测、不承诺收益
- 每条资源标「什么时候用」
- 有书的给微信读书入口，有官方资源的给官方入口；都没有的如实标「暂无公开资源」
