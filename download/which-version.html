三个版本怎么选

都是同一套内容（14 张表 / 14 个模板 / 场景卡 / Gate），只是装在不同的地方。你不需要会 AI，选一个照着走。

一句话选

你的情况选这个
不想上云，客户资料只在自己电脑里本地文件版
想要一个界面，早上能提醒我今天该联系谁WorkBuddy 版
客户天天问行情、问产品，我要当场能查，手机上也要用豆包版

三版差在哪

你每天打开什么电脑上一个文件夹 + 一个网页WorkBuddy 客户端里的工作台手机上的豆包
会主动提醒你吗不会，得自己跑一下会，4 个定时任务会，自动任务
能查行情/研报吗不能，只给链接弱，靠专家团强，8 个插件直连
客户资料在哪你自己的电脑你自己的电脑云端（飞书）
断网还能用吗能基本能不能
上手要多久半小时半天1 小时

1 本地文件版

谁用
客户名单你不敢往网上传，平时也不怎么用 AI 工具。
你打开的是
你电脑里的一个文件夹，加一个网页（双击就能看） 
SoloAdvisor-Workbench-v2/
├── START.md        三分钟上手：先跑哪两条命令
├── AGENTS.md       写入规则：AI 该写哪张表、别瞎写
├── CLAUDE.md       干活顺序：查资源 → 七步 → 过 Gate → 落盘
├── data/           14 张表（客户 / 跟进 / 产品 / 素材 / 活动 / 待办…）
├── clients/        一人一档：他真正担心什么
├── templates/      一页纸 / 建议书 / 复盘 / 纪要 / 沙龙 / 交接包
├── resources/      场景 33 / 工具 28 / Skill 51 / 库 75 / 模板 20
├── outputs/        交付物（按日期自动命名）
└── 脚本            board.py 看板 · check.py 体检 · log.py 写表 · bench.py 出网页
第一周你会做什么
  1. 解压，跑 python check.py，看到「通过 7 失败 0」就算装好
  2. 把 data/clients.csv 里 3 行 SAMPLE 换成你自己的客户
  3. 对 AI 说「今天见了张先生，他担心孩子出国那 80 万」，看它自己写进表
下载这个文件夹（zip，151KB）

2 WorkBuddy 版

谁用
你已经在用 WorkBuddy，想要个界面，不想天天自己跑命令。
你打开的是
WorkBuddy 客户端里的一个工作台，点开就能问
它替你干的事
  • 见客户前备料 —— 周备全（会前准备专家）
  • 持仓诊断 —— 理财财（财富管理专家）
  • 看行业 —— 严研行（行业研究专家）
  • 客户有异议 —— 单必成（销售教练）
  • 早上提醒 —— 4 个定时任务（今日跟进 / 周看板 / Gate 抽检 / 月度盘点）
第一周你会做什么
  1. 按配置文档建工作台，粘一段简介
  2. 挂 4 个专家 + 6 个技能
  3. 说「今天该联系谁」，看它能不能读你的客户表
下载配置包（zip）

3 豆包版

谁用
客户天天问行情问产品，你多数时候在手机上，没时间开电脑查。
你打开的是
手机上的豆包，随时能问
它替你干的事
  • 查行情、财报、研报 —— 8 个金融数据插件（万得 / 同花顺 / 东财 / 晨星 / 盈米…）
  • 客户问题当场答 —— 12 个技能 + 33 条场景卡
  • 记客户 —— 飞书多维表格 5 张表（客户 / 跟进 / 产品 / 素材 / 待办）
第一周你会做什么
  1. 建成工作台，粘简介，挂 4–6 个插件（别全挂，会乱选）
  2. 在飞书照文档建 5 张表
  3. 说「固收+ 现在能买吗」，看它是去查插件还是编数字
下载配置包（zip）

能不能换？能，数据不用重做

三版用的是同一套字段（客户 14 列、跟进 6 列、产品 12 列），所以：

从 → 到做什么代价
本地文件版 → WorkBuddy 版文件夹直接挂进去，加 4 专家 6 技能半天，数据不用搬
本地文件版 → 豆包版5 张表导成飞书多维表格，资料库传 5 个 md半天，数据上云
WorkBuddy 版 → 豆包版本地表导飞书，专家换成插件1 天，会丢私密性
豆包版 → 本地文件版飞书表导出 CSV，字段一一对应半天，更私密

真源只有一份：客户数据在你手里那份才是真源；上了豆包，飞书那份是副本。
别同时用两套：两个平台各记一半，一定对不上。
