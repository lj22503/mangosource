# MangoSource · 一鱼多吃发布指南

写法照搬那篇 PaiWork 小红书：**13 页图文长文，每页「一段文字 + 一张能自证的截图」**。正文不是引言，配图不是装饰——每个论点都有一张真实界面图支撑。

## 核对过的原文结构

P1 封面大字 → P2-3 痛点（工作割裂、翻笔记核对）→ P4 方案亮相 → P5-7 分区 tour → P8-11 首页怎么组织信息 → P12 为什么用它（不自己写代码的苦力活）→ P13 收尾。

版式三件套：白底黑字、关键词品牌橙高亮（橙字 + 暖橙底 #FBEEE4）、右上角圆圈编号；截图页用绿框圈重点。

## 手上有什么

| 文件 | 用途 |

13 页对应：封面 / 痛点 / 痛点细化 / 方案亮相 / 六大块 / 场景页 / 异动对照 / 首页更聪明 / 按处境组织 / 场景自证 / 方法页 / 为什么用它 / 收尾二维码。

## 公众号（整篇发）

1. 浏览器打开 `公众号文章-MangoSource.html`，全选复制，粘进后台编辑器。13 张图是 base64 内嵌的，会一起带过去。
2. HTML 有 3MB。若编辑器粘贴卡或过滤 data URI，删掉图，从 `../assets/xhs-post/` 手动上传 P01～P13，按正文顺序插回。
3. 摘要：**用券商软件看行情，用 AI 查公司，图表在另一个平台。资料越攒越多，却越来越难用。这次把它们收进了一个工作台。**
4. 原文链接：`https://mangosource.app.workbuddy.host/?sharecode=DYPP2BGOV7`

## 小红书 / 贴图号（原样发，不用拆）

这次和上一个版本不同：**13 页本身就是一个完整的小红书图文帖**，直接按 P01→P13 顺序发即可，不用重组。

- 首图 P01 封面，和原文一样三行大字 + 截图。
- 文案用主稿正文，末尾加话题标签：

> #AI工作台 #AI应用 #投资研究 #投研工作台 #研究工作流 #数据可视化 #效率工具 #投资工具

- 贴图号同理，图原样用，去掉话题标签。

## 朋友圈（一张图 + 短文案）

- 用 `P13-收尾.png`，里面有二维码，实测能扫开应用链接。
- 配文二选一：

> 把散落各处的投资资料，收进了一个工作台。扫码看看。

> 你问「这只能买吗」，它拆成五问，缺哪问就是答案。不荐股不预测。

## 改东西的时候

- 改文字 → 改 md。13 页图上的文字是另一套（在 `gen_xhs_style.py` 里），两边都要改才一致。
- 改图 → 图在 `../assets/xhs-post/`，HTML 是内嵌的，改完要重跑 `build_html.py`。
- 母本：md 是文章母本，脚本是配图母本，HTML 是派生物。别三边各改各的。

## 一条不能松的边界

13 页里保留了「不荐股 / 不预测 / 不承诺收益」。换平台不要删——这是合规底线，也是「投资平权」人设的一致性。真要挂价或做付费，这条要写得更硬。
